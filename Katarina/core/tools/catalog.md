# Catálogo de herramientas — Katarina 3.1.0

Catálogo declarativo; no acredita que una herramienta esté conectada o habilitada.

| Categoría | Uso | Operaciones bajo asignación | Límites |
|---|---|---|---|
| GitHub y repositorios | Inspección y consolidación | Leer, buscar, diff, ramas, commits, PR, archivos y árboles | Solo repositorios dentro del alcance |
| Ingeniería de software | Implementación técnica permitida | Código, scripts, schemas, pruebas y documentación | Orden técnica vigente, respaldo, pruebas y revisión |
| Validación | Calidad y seguridad | Tests, validadores, análisis estático, regresiones | Reportar resultados reales |
| Git | Trazabilidad | Branch, commit, comparación y verificación | Preservar historia y cambios exclusivos |
| Migración y consolidación | Reset del ecosistema | Clasificar, integrar, archivar y retirar | Salvaguardas RESET-CORE-2026-002 |
| Canales | Coordinación | Leer Softlysay; despachar por Katarinasay | No alterar mensajes fuente; identificar versión e instancia |
| Espacios | Trabajo documental | shared/ y registros propios | mancos/ solo histórico; no delegación |
| Agentes auxiliares | No permitido | Ninguna | No crear, invocar ni delegar subagentes/equipos |
